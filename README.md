# GeminiBar

A Windows 10/11 floating Gemini study assistant built around your requested workflow: small floating button, expandable rounded chat, clipboard screenshots from Snipping Tool, editable model IDs, thinking level, custom instructions, local encrypted API-key storage, chat follow-ups/new session, math rendering, opacity control, and a separate Gemini Live voice button.

## Build

The GitHub Actions workflow builds a self-contained Windows x64 EXE. No Visual Studio installation is needed on your own computer.

1. Open the Actions tab in this repository.
2. Open Build Windows EXE.
3. Select the latest successful run.
4. Download the GeminiBar-Windows-x64 artifact ZIP and extract GeminiBar.exe.

The app uses .NET 8 WPF. The Windows PC must have the Microsoft Edge WebView2 Evergreen Runtime for the chat and math renderer.

## Use

1. Launch GeminiBar.exe; the floating G button stays on top of other windows.
2. Open Settings, paste your Gemini API key, and save. The key is encrypted with Windows DPAPI for the current Windows user and isn't written into the JSON settings file.
3. Keep your PDF open and press Win + Shift + S. When the resulting image appears on the clipboard, GeminiBar detects it and opens the panel. You can also press Use clipboard image.
4. Type a question or leave the input blank to ask about the captured screenshot. Follow-ups include earlier turns in the current session.
5. Use New session to clear the current conversation, or Stop to cancel a text response.
6. In Settings, type the exact text-model and Live-model IDs, choose low/medium/high thinking (where supported), set opacity, and edit your study instructions.
7. Press Live to begin a real-time microphone/speaker session; press Stop Live to end it.

## Data and network behavior

- The API key is stored in %LOCALAPPDATA%\GeminiBar\api-key.dat, encrypted using Windows DPAPI with current-user scope.
- Preferences are stored in %LOCALAPPDATA%\GeminiBar\settings.json.
- Conversation history and captured images are kept in memory for the current session; they're sent to Google when you submit a request. They are not saved as local chat history.
- Live mode connects directly to Google's Gemini Live WebSocket endpoint with the saved API key. Treat the key as a secret and restrict it to the Gemini API in Google AI Studio.
- Mathematical notation is rendered with MathJax loaded from jsDelivr, so rendering LaTeX requires internet access.
- The GitHub build validates compilation and runs the app's built-in smoke test. That does not replace testing on every individual Windows PC/API account.

## Notes

This is a personal-use source project and is not digitally signed. Windows SmartScreen may show a warning for an unsigned executable. The EXE is generated by GitHub Actions; no API key is included in the build.
